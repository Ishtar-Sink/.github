# Ishtar Sink

Ferramentas livres e gratuitas para você não depender de assinatura.

Cada projeto aqui existe porque alguma coisa que deveria ser simples virou mensalidade:
ouvir a própria biblioteca de música, organizar as próprias contas, guardar as próprias
notas. São coisas que rodam bem num computador seu, com dados seus, e não precisam de
ninguém no meio cobrando por mês para permitir.

Nada aqui tem plano pago, versão "pro" ou funcionalidade guardada atrás de cadastro. Se um
projeto existe nesta organização, ele está inteiro no repositório.

## No que a gente acredita

**Você hospeda, você manda.** Todo projeto é feito para rodar na sua máquina ou no seu
servidor. Sem conta obrigatória, sem telemetria, sem nuvem nossa no meio. Se amanhã esta
organização sumir, o que você já instalou continua funcionando exatamente igual.

**Seus dados são arquivos seus.** Um banco SQLite, uma pasta de mídia, um JSON legível. Nada
de formato fechado que só a nossa ferramenta abre — se você quiser sair, é só levar os
arquivos.

**Libertar não é prejudicar.** A meta é tirar as pessoas da dependência de software pago, e
isso não passa por pirataria, por burlar sistema de ninguém nem por pegar carona no trabalho
alheio. Quando uma ferramenta daqui pode ser usada de um jeito que causa problema pra alguém,
a documentação diz isso na cara, em vez de fingir que a questão não existe.

**Documentação é parte do produto.** Um projeto que só você consegue rodar não é aberto de
verdade — é código publicado. Todo repositório aqui tem instruções de instalação, arquitetura
explicada e uma página do que costuma dar errado.

## Como isso é feito

Sem regra rígida de stack: cada projeto usa o que faz sentido para o problema dele. O que é
compartilhado entre todos:

- **Identidade visual única** — mesma paleta, mesma tipografia, mesmas escalas. Você
  reconhece um projeto do Ishtar Sink de longe.
- **Convenção de nomes** — todo produto leva o nome de um fenômeno astronômico cujo
  comportamento real descreve o que o software faz. Nebula é uma nuvem de poeira que junta
  matéria dispersa e forma estrelas; o player junta arquivos soltos e forma uma biblioteca.
- **Autohospedagem em primeiro lugar**, não como um extra depois.

As duas primeiras convenções estão escritas em
[docs/identidade-ecossistema.md](https://github.com/ishtar-sink/nebula/blob/main/docs/identidade-ecossistema.md),
dentro do repositório do Nebula.

## Contribuindo

Issue e pull request são bem-vindos em qualquer repositório. Duas coisas ajudam muito:

- **Abra uma issue antes de um PR grande.** Evita você escrever bastante código numa direção
  que não vai ser aceita.
- **Bug útil é bug reproduzível.** Diga o que você fez, o que esperava e o que aconteceu, com
  a versão e o sistema operacional.

Se você não programa, ainda dá para ajudar bastante: reportar o que quebrou, apontar
documentação confusa, ou dizer qual ferramenta paga te incomoda a ponto de valer um substituto
aberto.

## Sobre o nome

Ishtar Sink é uma região de Vênus no universo de *Destiny*, onde ficava a Ishtar Collective —
uma organização científica dedicada a investigar e arquivar conhecimento. A referência é
pessoal, e a escolha do arquivamento em vez da conquista não é acidente.

Ishtar Terra, por sinal, é uma região real de Vênus. O nome já era astronômico antes do jogo.
